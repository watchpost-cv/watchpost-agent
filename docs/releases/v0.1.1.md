# Watchpost Agent v0.1.1

Watchpost Agent v0.1.1 is a stable public-preview release.

- Adopts the canonical Gantry Core multi-account model and password hashes.
- Adds the shared-layout management console and adaptive launcher.
- Separates authentication-only and full resets with explicit confirmation.
- Makes resets recover invalid state and fixes protected-state inspection in
  the systemd lifecycle test.
- Pins Gantry Core v0.1.0 for reproducible standalone builds.
